BIP39 • BINAIRE

Comment lire votre plaque SATONA

Aucun code propriétaire. Chaque ligne contient simplement la position d’un mot BIP39 écrite en binaire.

Un mot → une position → 11 bits

La liste anglaise BIP39 contient 2 048 mots.

Chaque mot possède une position fixe comprise entre 0 et 2 047.

SATONA ne transforme pas arbitrairement le mot. SATONA prend simplement cette position et l’écrit en binaire sur 11 bits.

0 00000000000
1 00000000001
2 00000000010
3 00000000011
4 00000000100
ABOUT ↓ position 3 ↓ 00000000011

Pourquoi 11 cases ?

11 bits permettent de représenter 2 048 valeurs différentes. C’est exactement le nombre d’entrées de la liste BIP39.

211 = 2048

1 BIP39 word → 1 position (0–2047) → 11 bits → 1 SATONA line

Retrouver un mot depuis votre plaque

1024 512 256 128 64 32 16 8 4 2 1

Une case marquée représente 1. Une case vide représente 0.

Pour retrouver la position du mot, additionnez simplement les valeurs des cases marquées.

0 0 0 0 1 0 1 0 1 1 0

64 + 16 + 4 + 2 = 86

Le nombre obtenu correspond à la position du mot dans la liste BIP39.

11 squares ↓ binary number ↓ decimal number ↓ BIP39 position ↓ original word

Et si SATONA n’existe plus dans 20 ans ?

Votre plaque ne dépend pas de SATONA pour être décodée.

Le binaire est une notation mathématique universelle. Il n’existe aucune clé SATONA, aucun algorithme propriétaire et aucun serveur nécessaire pour interpréter les 11 cases.

Avec la liste BIP39 et les valeurs ci-dessous, vous pouvez retrouver chaque position manuellement, puis le mot correspondant dans la liste BIP39.

1024 512 256 128 64 32 16 8 4 2 1
SATONA plate → word position → BIP39 list → recovery phrase

Essayez vous-même

Cet outil pédagogique local convertit uniquement un nombre ou une chaîne de 11 bits. Il ne demande jamais de phrase de récupération et n’effectue aucune requête réseau.
