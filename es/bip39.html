Convierte una palabra BIP39 a binario

Cada palabra tiene una posición definida en la lista inglesa estandarizada BIP39, del 0 al 2047. SATONA convierte esta posición en un código binario de 11 bits. Estos 11 bits se representan después en una línea de la placa.

ability→ position 1→ 00000000001

Esta correspondencia también permite realizar la operación inversa: a partir de los 11 bits marcados en la placa, se puede recuperar la posición en la lista BIP39 y, por tanto, la palabra correspondiente.

¿Cómo funciona la conversión?

LISTA BIP392048 palabras
↓
POSICIÓNde 0 a 2047
↓
BINARIO11 bits
↓
SATONA11 posiciones en una línea

La lista inglesa BIP39 contiene 2048 palabras en un orden definido.

La posición de una palabra en esta lista constituye su índice.

Como 2048 = 2¹¹, 11 bits son suficientes para representar las 2048 posiciones posibles.

SATONA utiliza esta representación binaria para representar cada palabra en una línea de 11 posiciones.

Una correspondencia definida por BIP39

En la lista inglesa estandarizada BIP39, cada palabra ocupa una posición definida.

Esta correspondencia palabra → posición → binario es determinista: la misma palabra corresponde siempre al mismo índice y al mismo código binario de 11 bits dentro de esta lista.

abandon → position 0 → 00000000000ability → position 1 → 00000000001zoo → position 2047 → 11111111111

Este principio permite recuperar la palabra a partir del código binario almacenado en SATONA.

¿Por qué 11 bits?

2¹¹ = 2048

Once bits permiten representar exactamente las 2048 posiciones posibles de la lista BIP39.

En SATONA:

1 palabra = 1 posición = 11 bits = 1 línea
