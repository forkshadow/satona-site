Convertir un mot BIP39 en binaire

Chaque mot possède une position définie dans la liste anglaise BIP39 standardisée, de 0 à 2047. SATONA convertit cette position en un code binaire de 11 bits. Ce sont ces 11 bits qui sont ensuite reportés sur une ligne de la plaque.

ability→ position 1→ 00000000001

Cette correspondance permet également d’effectuer l’opération inverse : à partir des 11 bits marqués sur la plaque, retrouver la position dans la liste BIP39 puis le mot correspondant.

Comment fonctionne la conversion ?

LISTE BIP392048 mots
↓
POSITION0 à 2047
↓
BINAIRE11 bits
↓
SATONA11 positions sur une ligne

La liste anglaise BIP39 contient 2048 mots dans un ordre défini.

La position d’un mot dans cette liste constitue son index.

Comme 2048 = 2¹¹, 11 bits suffisent à représenter les 2048 positions possibles.

SATONA utilise cette représentation binaire pour reporter chaque mot sur une ligne de 11 positions.

Une correspondance définie par BIP39

Dans la liste anglaise BIP39 standardisée, chaque mot occupe une position définie.

Cette correspondance mot → position → binaire est déterministe : le même mot correspond au même index et au même code binaire de 11 bits dans cette liste.

abandon → position 0 → 00000000000ability → position 1 → 00000000001zoo → position 2047 → 11111111111

C’est ce principe qui permet de retrouver le mot à partir du code binaire conservé sur SATONA.

Pourquoi 11 bits ?

2¹¹ = 2048

Onze bits permettent donc de représenter exactement les 2048 positions possibles de la liste BIP39.

Sur SATONA :

1 mot = 1 position = 11 bits = 1 ligne

Un mot en ligne, jamais votre phrase complète

Les outils SATONA en ligne sont destinés à apprendre, convertir ou contrôler un mot isolé.
