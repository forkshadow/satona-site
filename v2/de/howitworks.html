Funktionsweise

Ein klarer Offline-Prozess.

Lernen Sie die binäre Kodierung mit Beispielen kennen. Dieses Werkzeug dient zum Lernen und Prüfen — nicht zur Eingabe einer vollständigen Wiederherstellungsphrase.

01

Umwandeln

Ermitteln Sie für jedes Wort den 11-Bit-Wert, vorzugsweise mithilfe der Offline-PDF.

02

Markieren

Eine Eins wird als Feld markiert, eine Null bleibt frei. Arbeiten Sie Zeile für Zeile.

03–04

Prüfen und aufbewahren

Prüfen Sie jedes Muster und bewahren Sie die Platte anschließend an einem sicheren, diskreten Ort auf.

Nur Demonstrationsmodus. Geben Sie keine vollständige Wiederherstellungsphrase ein. Verwenden Sie Beispielwörter oder nutzen Sie die herunterladbare PDF vollständig offline.

Einige Beispielwörter ausprobieren

Verwenden Sie abandon, ability oder ein anderes einzelnes BIP39-Wort. Die Felder bleiben gewöhnliche, auswählbare Eingabefelder.

BIP39-PDF herunterladen

Vor der Aufbewahrung prüfen

Muster prüfen

Jede Zeile hat elf Positionen. Prüfen Sie jedes Ausgangswort und seine Binärfolge erneut, bevor Sie das nächste Wort markieren.

Häufige Fehler vermeiden

Nehmen Sie sich Zeit, verlassen Sie sich nicht auf Ihr Gedächtnis und fotografieren oder speichern Sie die vollständige Wiederherstellungsphrase niemals digital.
