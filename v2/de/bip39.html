BIP39

Ein BIP39-Wort verstehen und umwandeln

BIP39 ist ein Standard zur Darstellung von Wiederherstellungsphrasen anhand einer geordneten Liste mit 2.048 Wörtern.

Geben Sie Ihre vollständige Wiederherstellungsphrase niemals hier ein.Verwenden Sie dieses Tool Wort für Wort zum Lernen oder Prüfen. Für eine echte Wiederherstellungsphrase sollten Sie die heruntergeladene BIP39-Liste verwenden und offline arbeiten.

Was ist BIP39?

Die englische BIP39-Liste enthält 2.048 Wörter in einer festgelegten Reihenfolge.

Jedes Wort hat einen Index zwischen 0 und 2047.

Da 2.048 = 2¹¹ gilt, lässt sich dieser Index mit genau 11 Bits darstellen.

ability→1→00000000001

Auf SATONA entsprechen diese 11 Bits den 11 Positionen einer Zeile.

1 = markieren0 = leer lassen

Eine standardisierte und stabile Liste

Die englische BIP39-Wortliste für Wiederherstellungsphrasen enthält 2.048 Wörter in einer festgelegten Reihenfolge.

Innerhalb dieser Liste entspricht dasselbe Wort immer demselben Index und damit demselben 11-Bit-Binärcode.

abandon → index 0 → 00000000000ability → index 1 → 00000000001zoo → index 2047 → 11111111111

Durch diese Zuordnung kann SATONA Wörter codieren, ohne die Wörter selbst auf die Platte zu schreiben.

BIP39 → 11 BITS
