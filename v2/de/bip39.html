Ein BIP39-Wort in Binärcode umwandeln

Jedes Wort hat eine definierte Position in der standardisierten englischen BIP39-Wortliste, von 0 bis 2047. SATONA wandelt diese Position in einen 11-Bit-Binärcode um. Diese 11 Bits werden anschließend in einer Zeile der Platte markiert.

ability→ Position 1→ 00000000001

Diese Zuordnung funktioniert auch in umgekehrter Richtung: Aus den 11 auf der Platte markierten Bits lässt sich die Position in der BIP39-Liste und damit das entsprechende Wort bestimmen.

Wie funktioniert die Umwandlung?

SATONA11 Positionen in einer Zeile

Die englische BIP39-Liste enthält 2048 Wörter in einer festgelegten Reihenfolge.

Die Position eines Wortes in dieser Liste ist sein Index.

Da 2048 = 2¹¹ gilt, reichen 11 Bits aus, um alle 2048 möglichen Positionen darzustellen.

SATONA nutzt diese binäre Darstellung, um jedes Wort in einer Zeile mit 11 Positionen einzutragen.

Eine durch BIP39 definierte Zuordnung

In der standardisierten englischen BIP39-Wortliste nimmt jedes Wort eine definierte Position ein.

Diese Zuordnung Wort → Position → Binärcode ist deterministisch: Dasselbe Wort entspricht in dieser Liste demselben Index und demselben 11-Bit-Binärcode.

abandon → Position 0 → 00000000000ability → Position 1 → 00000000001zoo → Position 2047 → 11111111111

Nach diesem Prinzip lässt sich das Wort aus dem auf SATONA gespeicherten Binärcode wiederherstellen.

Warum 11 Bits?

2¹¹ = 2048

Elf Bits können somit genau die 2048 möglichen Positionen der BIP39-Liste darstellen.

Auf SATONA:

1 Wort = 1 Position = 11 Bits = 1 Zeile
