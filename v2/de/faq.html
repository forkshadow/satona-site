FAQ

Alle Fragen zu SATONA beantwortet

Produkt, BIP39, Wallets und Sicherheit: die wichtigsten Antworten an einem Ort.

01

SATONA

Ist SATONA eine elektronische Wallet?

Nein. SATONA ist ein physischer Träger, auf dem die Informationen einer BIP39-Wiederherstellungsphrase binär gesichert werden.

Werden meine Kryptowährungen auf der SATONA-Platte gespeichert?

Nein. SATONA speichert keine digitalen Vermögenswerte. Die Platte enthält nur die binäre Darstellung der Wiederherstellungsinformationen, die Sie darauf festhalten.

Was enthält das SATONA-Kit genau?

Das Kit enthält eine massive SATONA-Messingplatte, einen automatischen Körner, zwei Spitzen, eine hochwertige Magnetbox, eine Anleitung und einen QR-Code zur SATONA-Anleitung.

Wie viele Wörter kann ich sichern?

SATONA kann bis zu 24 BIP39-Wörter codieren: Wörter 1–12 auf der Vorderseite und Wörter 13–24 auf der Rückseite.

02

Wallets & Kryptowährungen

Was unterscheidet eine Krypto-Plattform von einer persönlichen Wallet?

Eine Börsenplattform kann die für den Zugriff erforderlichen Schlüssel im Auftrag ihrer Nutzer verwahren. Bei einer Non-Custodial Wallet kontrolliert der Nutzer seine Schlüssel selbst. Nutzt die Wallet eine Wiederherstellungsphrase, kann diese den Zugriff auf einer kompatiblen Wallet in der Regel wiederherstellen.

Was ist eine Custodial Wallet?

Bei einer Custodial Wallet verwahrt oder kontrolliert ein Dritter die Schlüssel für den Zugriff auf die Vermögenswerte. Der Nutzer ist daher teilweise von diesem Anbieter abhängig.

Was ist eine Non-Custodial Wallet?

Bei einer Non-Custodial Wallet behält der Nutzer die Kontrolle über seine Schlüssel und ist direkt für den Schutz der Wiederherstellungsphrase und weiterer Wiederherstellungsinformationen verantwortlich.

Was ist eine Cold Wallet oder Hardware Wallet?

Eine Hardware Wallet bewahrt private Schlüssel auf und verwendet sie, während ihre Exposition gegenüber verbundenen Geräten begrenzt wird. Ledger und Trezor sind bekannte Beispiele. Sie erfüllt nicht dieselbe Aufgabe wie SATONA.

Was unterscheidet SATONA von einer Hardware Wallet wie Ledger oder Trezor?

Eine Hardware Wallet verwahrt und verwendet private Schlüssel für Wallet-Vorgänge. SATONA ist keine Wallet: Es sichert BIP39-Wiederherstellungsinformationen physisch, damit sie bei Bedarf rekonstruiert werden können. Beide Funktionen können sich ergänzen.

Was passiert, wenn ich meine Hardware Wallet verliere oder beschädige?

Wenn die Wallet eine kompatible Wiederherstellungsphrase nutzt und diese korrekt gesichert wurde, kann sie den Zugriff auf einem kompatiblen Gerät oder in einer kompatiblen Wallet in der Regel wiederherstellen. SATONA dient der physischen Sicherung dieser Information.

03

BIP39 & Codierung

Ist SATONA mit meiner Wallet kompatibel?

SATONA ist für Wallets vorgesehen, die eine englische BIP39-Wiederherstellungsphrase mit bis zu 24 Wörtern nutzen. Prüfen Sie zuvor die Dokumentation Ihrer Wallet, denn nicht jede Wallet nutzt BIP39.

Warum hat jedes Wort 11 Felder?

Die englische BIP39-Liste enthält 2.048 Wörter mit Indizes von 0 bis 2.047. Da 2.048 = 2¹¹ gilt, können 11 Bits jeden Index darstellen.

Muss ich die Wörter eingravieren?

Nein. Markiert wird der binäre 11-Bit-Index jedes BIP39-Wortes, nicht das Wort selbst.

Was bedeuten 1 und 0 auf SATONA?

1 bedeutet: Feld markieren. 0 bedeutet: Feld leer lassen. Jede Zeile stellt den 11-Bit-Binärcode eines BIP39-Wortes dar.

04

Sicherheit

Warum muss die Wiederherstellungsphrase so sorgfältig geschützt werden?

Wer Ihre vollständige Wiederherstellungsphrase besitzt, könnte die zugehörige Wallet auf einem kompatiblen Gerät wiederherstellen und auf die geschützten Vermögenswerte zugreifen. Behandeln Sie sie deshalb als hochsensible Information.

Soll ich hier meine vollständige Wiederherstellungsphrase eingeben?

Nein. Geben Sie Ihre vollständige Phrase niemals auf satona.fr oder einer anderen Website ein. Laden Sie für den echten Einsatz das BIP39-PDF herunter und arbeiten Sie vollständig offline.

Kann ich SATONA ohne Internetverbindung verwenden?

Ja. Nach dem Download der BIP39-Liste können Umwandlung und Markierung vollständig offline erfolgen; das ist die empfohlene Methode.

Enthält SATONA meine privaten Schlüssel?

Nein. SATONA speichert weder Kryptowährungen noch aktive private Schlüssel oder eine elektronische Wallet. Es enthält nur die binäre Darstellung der von Ihnen gewählten Wiederherstellungsinformationen.

05

Verwendung des Kits

Wie setze ich den Körner zusammen?

Schrauben Sie das konische Ende ab, setzen Sie eine der mitgelieferten Spitzen ein und schrauben Sie alles wieder zusammen. Die bebilderte Anleitung zeigt den vollständigen Ablauf.

Wie prüfe ich die Markierung?

Setzen Sie die Spitze mittig an, drücken Sie bis zum Klick und prüfen Sie anschließend Lesbarkeit sowie jedes markierte und freie Feld anhand Ihrer Vorlage.

Wie werden Vorder- und Rückseite verwendet?

Tragen Sie Wörter 1–12 auf der Vorderseite und Wörter 13–24 auf der Rückseite in der ursprünglichen Reihenfolge ein.

Wo finde ich die Anleitung?

Der QR-Code im Kit führt zur SATONA-Anleitung. Zusätzlich stehen die Seite Funktionsweise und das BIP39-PDF für die Offline-Umwandlung bereit.
