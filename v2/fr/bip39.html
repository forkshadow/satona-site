BIP39

Comprendre et convertir un mot BIP39

BIP39 est un standard utilisé pour représenter les phrases de récupération à partir d’une liste ordonnée de 2 048 mots.

Ne saisissez jamais votre phrase de récupération complète ici.Utilisez cet outil mot par mot pour apprendre ou vérifier. Pour une phrase réelle, privilégiez la liste BIP39 téléchargée et travaillez hors ligne.

Qu’est-ce que BIP39 ?

La liste anglaise BIP39 contient 2 048 mots dans un ordre défini.

Chaque mot possède un index compris entre 0 et 2047.

Comme 2 048 = 2¹¹, cet index peut être représenté par exactement 11 bits.

ability→1→00000000001

Sur SATONA, ces 11 bits correspondent aux 11 positions d’une ligne.

1 = marquer0 = laisser vide

Une liste standardisée et stable

La liste anglaise BIP39 utilisée pour les phrases de récupération comporte 2 048 mots dans un ordre défini.

Dans cette liste, un même mot correspond toujours au même index, et donc au même code binaire de 11 bits.

abandon → index 0 → 00000000000ability → index 1 → 00000000001zoo → index 2047 → 11111111111

Cette correspondance permet à SATONA d’encoder les mots sans inscrire les mots eux-mêmes sur la plaque.
