BIP39

Understand and convert a BIP39 word

BIP39 is a standard used to represent recovery phrases from an ordered list of 2,048 words.

Never enter your complete recovery phrase here.Use this tool one word at a time for learning or verification. For a real recovery phrase, use the downloaded BIP39 list and work offline.

What is BIP39?

The English BIP39 list contains 2,048 words in a defined order.

Each word has an index between 0 and 2047.

Because 2,048 = 2¹¹, this index can be represented by exactly 11 bits.

ability→1→00000000001

On SATONA, these 11 bits correspond to the 11 positions in one line.

1 = mark0 = leave empty

A standardized and stable list

The English BIP39 word list used for recovery phrases contains 2,048 words in a defined order.

Within this list, the same word always maps to the same index and therefore to the same 11-bit binary value.

abandon → index 0 → 00000000000ability → index 1 → 00000000001zoo → index 2047 → 11111111111

This mapping allows SATONA to encode words without writing the words themselves on the plate.

BIP39 → 11 BITS
