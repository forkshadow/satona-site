BIP39 • BINÄR

So lesen Sie Ihre SATONA-Platte

Kein proprietärer Code. Jede Zeile enthält lediglich die binär geschriebene Position eines BIP39-Wortes.

Ein Wort → eine Position → 11 Bits

Die englische BIP39-Liste enthält 2.048 Wörter.

Jedes Wort hat eine feste Position zwischen 0 und 2.047.

SATONA wandelt das Wort nicht willkürlich um. SATONA nimmt lediglich diese Position und schreibt sie als 11-Bit-Binärzahl.

0 00000000000
1 00000000001
2 00000000010
3 00000000011
4 00000000100
ABOUT ↓ position 3 ↓ 00000000011

Warum 11 Felder?

Mit 11 Bits lassen sich 2.048 verschiedene Werte darstellen. Das entspricht genau der Anzahl der Einträge in der BIP39-Liste.

211 = 2048

1 BIP39 word → 1 position (0–2047) → 11 bits → 1 SATONA line

Ein Wort von Ihrer Platte wiederfinden

1024 512 256 128 64 32 16 8 4 2 1

Ein markiertes Feld steht für 1. Ein leeres Feld steht für 0.

Um die Wortposition zu ermitteln, addieren Sie einfach die Werte der markierten Felder.

0 0 0 0 1 0 1 0 1 1 0

64 + 16 + 4 + 2 = 86

Die erhaltene Zahl entspricht der Position des Wortes in der BIP39-Liste.

11 squares ↓ binary number ↓ decimal number ↓ BIP39 position ↓ original word

Was, wenn SATONA in 20 Jahren nicht mehr existiert?

Ihre Platte lässt sich unabhängig von SATONA entschlüsseln.

Binärzahlen sind eine universelle mathematische Schreibweise. Zum Lesen der 11 Felder sind weder ein SATONA-Schlüssel noch ein proprietärer Algorithmus oder Server erforderlich.

Mit der BIP39-Liste und den folgenden Werten können Sie jede Position von Hand ermitteln und anschließend das entsprechende Wort in der BIP39-Liste finden.

1024 512 256 128 64 32 16 8 4 2 1
SATONA plate → word position → BIP39 list → recovery phrase

Probieren Sie die Umwandlung aus

Dieses lokale Lernwerkzeug wandelt ausschließlich eine Zahl oder eine 11-Bit-Folge um. Es fragt niemals nach einer Wiederherstellungsphrase und sendet keine Netzwerkanfrage.
